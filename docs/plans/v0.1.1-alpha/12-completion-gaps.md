## Completion and release profiles

The original full-alpha completion rule remains strict: it cannot be called
complete while any matrix row is `partial`, `deferred`, or `blocked`, or while
the alpha harness reports a deferred stage. Run
`bash scripts/audit-alpha-completion.sh --profile full` for that gate.

The published release used the explicitly narrower `bounded-alpha` profile. It
included only rows with `release_claim=alpha-required`; the ten rows with
`release_claim=post-alpha` remain `partial`, were excluded from the release
claim, and stay tracked by G1-G8. Run
`bash scripts/audit-alpha-completion.sh --profile bounded` for the bounded
release gate. This is a scope change, not a metadata-only promotion of
unfinished work.

Local verification on 2026-08-03: `cargo test -q -p aura-codegen --lib`
passed all 314 tests, including generated TCP listen/accept/read/close and
async cancellation/finally regressions; `cargo check --workspace` passed, and
`./scripts/sanitizer-smoke.sh` passed every listed native, Aura, HTTP, and
async-I/O case. The full profile remains intentionally blocked by the ten
post-alpha rows above; these results validate the implemented bounded contract
and do not promote external-host, registry, TLS, HTTP/2+, or open-generic
claims.

The G1 slice now includes UTF-8 byte iteration for `String` values across an
async CFG await, with repeated-join and queued-cancellation native coverage.
Richer aggregate element ownership remains open under ASYNC-003. Aggregate
enum pattern bindings now resolve generic field types and use generated
clone/drop hooks for value structs, interfaces, functions, foreign handles,
and heap-class references across the general CFG frame; the remaining work is
broader arbitrary aggregate/control-flow coverage.
Discarded joins also use a named owned Result temporary and typed drop hook;
bare joins no longer leak aggregate payloads.
The general CFG fallback also merges same-typed locals declared in different
branch arms, preserving aggregate ownership across the shared frame.
