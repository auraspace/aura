## Install

```bash
curl -fsSL https://aura.fadosoft.com/install.sh | AURA_VERSION=0.1.1-alpha.7 bash
aura version
avm --list
```

## Highlights

- Improved TLS connection handling with binary I/O and timeout support.

## Known limits

- This alpha does not promise a stable language or runtime ABI.
- Windows amd64 and arm64 remain tier-two policy targets and are not published
  artifacts until native acceptance evidence exists.
- Hosted registry proxy serving, general async lowering, richer async I/O, and
  broader native evidence remain follow-up work.
