| Field       | Value             |
| ----------- | ----------------- |
| **Version** | `0.1.1-alpha.5`   |
| **Date**    | 2026-08-06        |
| **Status**  | Published release |
| **Tag**     | `v0.1.1-alpha.5`  |

## Install

```bash
curl -fsSL https://aura.pilotworks.dev/install.sh | AURA_VERSION=0.1.1-alpha.5 bash
aura version
avm --list
```

## Highlights

- Expanded object-oriented language support with companion objects, abstract
  methods, `super` calls, interface default methods, secondary constructors,
  default arguments, variadic arrays, and method/free-function overloads.
- Improved generic interface and constructor resolution, including generic
  interface defaults and secondary-constructor argument upcasting.
- Refreshed dogfood examples with the new Todo, Notes, and Dotenv applications,
  plus updated testing expectations and HTTP example cleanup.
- Fixed ownership handling for boxed `String` locals in expression lowering.
- Added a manual GitHub release workflow for building and publishing the
  multi-platform alpha artifacts.

## Known limits

- This alpha does not promise a stable language or runtime ABI.
- Windows amd64 and arm64 remain tier-two policy targets and are not published
  artifacts until native acceptance evidence exists.
- Live registry publication, general async lowering, richer async I/O, and
  broader native evidence remain follow-up work.

## Verify the release

Run the offline acceptance gate from a clean checkout:

```bash
bash scripts/release-acceptance.sh
```

The tag-triggered workflow publishes Unix artifacts for Linux amd64/arm64 and
macOS arm64/amd64 after the required signing and acceptance checks pass.
