| Field       | Value             |

| **Date**    | 2026-08-06        |

## Install

```bash
curl -fsSL https://auraspace.github.io/aura/install.sh | AURA_VERSION=0.1.1-alpha.6 bash
aura version
avm --list
```

## Highlights

- Hardened release acceptance progress reporting and corrected the gate
  condition used to determine whether the acceptance run can complete.
- Refined registry and publication workflows for direct Git-origin package
  support, including origin-compatible release acceptance scripts.
- Expanded Aura syntax highlighting to recognize the latest language keywords.

## Known limits

- This alpha does not promise a stable language or runtime ABI.
- Windows amd64 and arm64 remain tier-two policy targets and are not published
  artifacts until native acceptance evidence exists.
- Hosted registry proxy serving, general async lowering, richer async I/O, and
  broader native evidence remain follow-up work.

## Verify the release

Run the offline acceptance gate from a clean checkout:

```bash
bash scripts/release-acceptance.sh
```

The release workflow publishes signed Unix artifacts for Linux amd64/arm64 and
macOS arm64/amd64 after the required acceptance checks pass.
