## Install

```bash
curl -fsSL https://aura.pilotworks.dev/install.sh | AURA_VERSION=0.1.1-alpha.8 bash
aura version
avm --list
```

## Highlights

- LLVM backend lowering is now complete across generic values, arrays, strings,
  exceptions, inheritance dispatch, and try/catch/finally control flow.
- Runtime and codegen gained stronger ownership cleanup, typed GC frame maps,
  incremental collection barriers, and platform-sized descriptor handling.
- The release pipeline now validates runtime archive metadata, checksum records,
  fuzz targets, and the multi-platform toolchain bundle more strictly.
- Documentation and deployment tooling were refreshed for the Cloudflare Pages
  site and the versioned runtime archive layout.

## Known limits

- Windows amd64/arm64 remain tier-2 policy targets and are not published.
- General async lowering, richer async I/O/HTTP handles, and broader native-host
  evidence remain outside this alpha's release contract.
- Registry proxy serving and checksum-database services remain deferred; direct
  Git-origin consumption and immutable lock pins are supported.
