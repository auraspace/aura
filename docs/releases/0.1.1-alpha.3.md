## Install

```bash
curl -fsSL https://aura.pilotworks.dev/install.sh | AURA_VERSION=0.1.1-alpha.3 bash
aura version
avm --list
```

This patch release hardens async ownership and makes the release gate reliable
across Linux and macOS hosts. It remains an experimental alpha and does not
promise a stable language or runtime ABI.

## Highlights

- Fixed async CFG match bindings so heap values are rooted in the task frame,
  avoiding stale poll-stack references after an `await` and forced GC.
- Tightened ownership and cleanup coverage for async payloads, foreign handles,
  HTTP errors, and nested task outcomes.
- Aligned workspace tests with the CI sanitizer policy: broad behavior tests
  run with leak detection disabled, while the dedicated sanitizer smoke gate
  retains leak detection and validates the ownership boundary.
- Added release acceptance coverage for Linux amd64 packaging, install smoke,
  cross-host artifact inspection, corpus/regression gates, and Clippy.
- Refreshed the homepage code showcase, AuraCanvas interaction, installation
  examples, and current release metadata.

## Known limits

- Credentialed production registry publishing and update flows remain deferred;
  acceptance coverage uses local fixtures.
- Linux arm64 is now included in the supported native target matrix. Windows
  artifacts remain policy-only; the shipped matrix is Linux amd64/arm64 and
  macOS amd64/arm64.
- This alpha does not promise a stable language or runtime ABI.
- See [`agents/debts.md`](../../agents/debts.md) for tracked technical debt.
