## Install

```bash
curl -fsSL https://aura.fadosoft.com/install.sh | AURA_VERSION=0.1.1-alpha.4 bash
aura version
avm --list
```

This alpha expands the typed standard-library surface and strengthens the
compiler, runtime, tooling, and multi-platform release path. It remains an
experimental release and does not promise a stable language or runtime ABI.

## Highlights

- Added recursive JSON decoding for primitive arrays, classes, structs, unit
  enums, and generic nested values, with bounded traversal and ownership-safe
  handling.
- Added typed streaming and transport outcomes across `std.http` and
  `std.stream`, plus broader TLS, UDP, WebSocket, multipart, compression, and
  cryptography coverage.
- Added opt-in generic type and interface reflection metadata, deterministic
  advanced `std.test` hooks, benchmark discovery, and iterable collection
  snapshots.
- Improved multi-level generic substitution, async return layouts, owned task
  outcomes, precise typed GC tracing, signal shutdown, logging, and fail-closed
  intrinsic runtime boundaries.
- Expanded LSP completion, cancellation, binding identity, references, and
  rename behavior while adding Linux arm64 release support and tier-two host
  recognition.
- Hardened release packaging with a target-neutral sysroot, SHA-256 coverage,
  native regression linking, and cross-target acceptance policy checks.

## Known limits

- This alpha does not promise a stable language or runtime ABI.
- Credentialed production registry publishing and live update flows remain
  deferred; release acceptance uses local fixtures.
- Windows amd64 and arm64 remain tier-two policy targets and are not published
  artifacts until native acceptance evidence exists.
- See [`agents/debts.md`](../../agents/debts.md) for tracked technical debt.
